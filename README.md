# 🎬 YouTube Downloader (MP3 & MP4)

🎵 YouTube Playlist → MP3  
🎥 YouTube Video / Playlist → MP4 (1080p)

A simple Python tool using yt-dlp and FFmpeg to download YouTube content as high-quality MP3 or 1080p MP4.

## ✅ Features
- MP3: Playlist audio → MP3
- MP4: Video or playlist → MP4 up to 1080p
- Auto numbering & clean filenames
- Video + audio merging

## 📂 Output

MP3:
mp3/Playlist Name/01 - Video Title.mp3

MP4:
mp4/Video Title.mp4

## 🛠 Requirements
- Python 3.8+
- yt-dlp
- FFmpeg

Install:
pip install -U yt-dlp

Check FFmpeg:
ffmpeg -version
