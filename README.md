🎵 YouTube Playlist to MP3 Downloader

A simple Python tool that downloads an entire YouTube playlist and converts each video into a high-quality MP3 file automatically using yt-dlp and FFmpeg.

Perfect for:
Music playlists
Podcasts
Lectures
Offline listening
Audio editing

📂 Output Structure
After running the script, files will be saved like this:
mp3/
 └── Playlist Name/
      ├── 01 - Video Title.mp3
      ├── 02 - Video Title.mp3
      ├── 03 - Video Title.mp3
